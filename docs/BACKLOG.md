## Godot 클라이언트 (기술)

- [ ] **반응형 테이블 레이아웃** — 지금은 1280×720 고정 + 레터박스라 폰에서 터치 타깃이 권장치(44 px)에 못 미친다. 실측: 폰 가로(844×390, 배율 0.542)에서 카드 42×60, 액션 버튼 108×21, 사기 도구 버튼 114×24, 상단 아이콘 15×14. 44 px를 넘기려면 버튼 높이가 설계 기준 81 px여야 하므로 좁은 화면용 두 번째 배치가 필요하다. 세로 화면은 v1.0.2에서 가로 유도 안내로 처리했다

- [ ] 런 이어하기(시드 + 액션 로그) — 웹/Godot 공통 포맷 (GDD §13.5)
- [ ] 게임패드 입력 매핑(현재 마우스 + Enter/C/P/Esc)
