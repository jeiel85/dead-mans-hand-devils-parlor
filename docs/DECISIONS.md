# 결정 기록 (되돌리기 어려운 결정만)

형식: 배경 → 선택지 → 결정 → 근거 → 되돌릴 때의 비용.

## D-001 · 본 개발 엔진: Godot 4.3+(C#) 권장, Unity 대안 — 2026-09-09 (원본 유지)

- **선택지**: Godot 4 C# / Unity 2022 LTS·6 / 웹 기술(Three.js 등)로 본 개발.
- **결정**: Godot 4.3+ C# 우선. Unity는 팀 확대·콘솔 포팅이 확정될 때 재검토.
- **근거**: 1인 개발 이터레이션 속도, 경량 빌드, 웹/모바일 익스포트, 로열티 없음. 2.5D(로우폴리 환경 + 2D 캐릭터)에 충분.
- **되돌릴 비용**: 코어 룰은 순수 로직(D-003)이라 포팅 비용이 낮다. 연출·에셋 파이프라인은 엔진 종속이므로 5주차 이전에 확정해야 한다.

## D-002 · 검증용 웹 프로토타입은 바닐라 JS, 빌드 도구 없음 — 2026-09-10

- **선택지**: 즉시 Godot로 시작 / React·Vite 웹 / 바닐라 ES 모듈.
- **결정**: 바닐라 ES 모듈 + 정적 호스팅(GitHub Pages).
- **근거**: 설계서의 룰·밸런스를 **가장 빨리 플레이 가능한 형태로 검증**하고 링크 하나로 공유하는 것이 목적. 빌드 단계·의존성이 없어야 링크가 오래 살아남는다. 사용자의 다른 저장소 관례(단일 HTML·외부 에셋 0)와도 맞다.
- **되돌릴 비용**: 프로토타입은 폐기 전제. 엔진(`rules.js`)·AI·수치는 C#으로 포팅한다.

## D-003 · 엔진은 순수 함수 + 이벤트 로그, 모든 무작위는 시드 RNG — 2026-09-10

- **선택지**: UI와 로직 결합 / 로직 분리 + `Math.random` / 로직 분리 + 시드 RNG + 이벤트.
- **결정**: 시드 RNG(xmur3 → mulberry32) + 액션이 이벤트를 남기는 순수 엔진.
- **근거**: 같은 코드로 UI·테스트·시뮬레이터·(미래) 고스트 재생기를 돌릴 수 있다. 버그 재현·데일리 시드·세이브(시드 + 액션 로그)가 공짜로 따라온다.
- **되돌릴 비용**: 높음. 고스트·세이브 포맷이 이 결정 위에 서므로 본 개발에서도 유지한다.

## D-004 · 실린더는 테이블 공유 1정, 순차 챔버, 구성 공개 — 2026-09-10

- **선택지**: 《Liar's Bar》식 개인 리볼버(각자 1/6→1/5…) / 공유 1정 + 구성 공개 + 순차 챔버(《Buckshot》식).
- **결정**: 공유 1정.
- **근거**: 1v1 구조에서 정보 게임(남은 실탄 세기)과 사기 도구(거울·납 탄환)가 모두 "다음 챔버"라는 하나의 대상에 걸려 룰이 단순해진다. 다인 테이블 도입 시 재검토.
- **되돌릴 비용**: 중간. `RevolverCylinder`를 플레이어별 인스턴스로 바꾸면 AI의 `pLive` 계산과 도구 효과 범위가 달라진다.

## D-005 · 고스트 데이터는 결정 로그 + 시드, 커서 궤적은 수집하지 않음 — 2026-09-10

- **선택지**: 원본안(마우스 궤적·망설임·시선) / 결정 로그 + 망설임 시간만.
- **결정**: 결정 로그 + 0.1초 양자화 망설임 시간. 옵트인, 익명 기본.
- **근거**: 재생에 필요한 것은 결정뿐이고, 궤적은 입력 장치마다 의미가 다르며 개인정보 리스크만 키운다.
- **되돌릴 비용**: 낮음(필드 추가는 가능). 단, 한 번 수집한 데이터는 되돌릴 수 없으므로 보수적으로 시작한다.

## D-006 · 배포: GitHub Pages, `main` 브랜치 루트에서 직접 서빙 — 2026-09-10

- **선택지**: Actions 기반 Pages 배포 / `gh-pages` 브랜치 / `main` 루트(legacy).
- **결정**: `main` 루트. 빌드가 없으므로 배포 파이프라인이 필요 없다.
- **근거**: 사용자의 기존 저장소들과 동일한 방식. 실패 지점이 하나 줄어든다.
- **되돌릴 비용**: 매우 낮음(저장소 설정 한 번).

## D-007 · 인앱 결제·가챠·실화폐 베팅 없음 — 2026-09-10

- **결정**: 유료 단품만.
- **근거**: 도박·자해 묘사와 실구매가 결합되면 등급·플랫폼 정책 리스크가 급격히 커진다(GDD §16 R-2).
- **되돌릴 비용**: 매우 높음(평판·심의). 되돌리지 않는 전제로 설계한다.
