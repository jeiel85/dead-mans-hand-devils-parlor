### 밸런스 수치 확정 (시뮬레이션 근거)

- 플레이어 HP 3, 층 클리어 시 +1 회복, 전리품에 붕대 고정.
- 시작 도구: 거울 1 · 밑장빼기 1 · 납 탄환 1 · 계약서 0.
- 딜러 HP: 1 / 2 / 3 / 3 / 3 / 4 / 4. 실린더: 2-4-0 / 2-4-0 / 3-2-1 / 3-3-0 / 3-2-1 / 4-2-0 / 4-1-1.
- 결과: 초심자 봇 승률 3.1%, 숙련 봇 50.7%, B1 통과율 86~96%.
