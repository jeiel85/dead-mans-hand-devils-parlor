## 1. 바이럴 인디 게임 벤치마킹 및 심층 분석

### 1.1 분석 대상

- **대표 레퍼런스**: 《Liar's Bar (라이어스 바)》, 《Buckshot Roulette (벅샷 룰렛)》, 《Balatro (발라트로)》, 《Inscryption (인스크립션)》  
- **장르 특성**: 테이블탑 심리전, 블러핑(속임수), 러시안 룰렛, 비대칭 정보 기반 서든데스

### 1.2 바이럴 핵심 성공 요인 (Viral Drivers)

1. **스트리머 및 숏폼(Short-form) 알고리즘 최적화**  
   - **압축된 마이크로 클라이맥스(Micro-Climax)**: 턴당 15초~30초 내에 [패 선언] -> [의심/수용] -> [격발/공개]의 완결된 드라마가 형성되어 틱톡/쇼츠 스와이프를 멈추게 함.  
   - **극단적인 리액션 유발**: 리볼버의 공포탄 찰칵 소리와 실탄의 폭발음, 목숨이 걸린 방아쇠를 당기는 순간의 감정 롤러코스터가 시청자에게 직접 전이됨.  
2. **극단적인 룰의 단순성 (Low Friction)**  
   - 복잡한 룰북이나 카드 효과 암기 없이 "숫자가 맞는지 의심한다", "실탄이냐 공포탄이냐"라는 직관적 룰 덕분에 누구나 3초 만에 룰을 이해하고 관전 가능.  
3. **다이제틱(Diegetic) 미니멀 인터랙션**  
   - 인위적인 2D HUD 대신 테이블 위의 소품(체력 카운터 담배/제세동기, 돋보기, 샷건)을 직접 집어서 사용하는 촉각적(Tactile) 몰입감.

### 1.3 나쁜 요소 및 기존 게임의 한계점 (Pain Points)

1. **5~10시간 이내의 급속한 콘텐츠 소진 및 피로도 (Content Burnout)**  
   - 패턴의 정형화(Solving): 최적 수(Nash Equilibrium)가 드러나면 심리전이 단순 확률 계산 및 운 싸움으로 퇴화함.  
2. **싱글 플레이의 깊이 부재**  
   - 《Buckshot Roulette》은 뛰어난 연출에도 불구하고 AI 패턴의 한계로 반복성이 떨어지며, 《Liar's Bar》는 싱글 모드가 전무해 매치메이킹 풀에 게임 수명이 종속됨.  
3. **공개 멀티플레이의 트롤링 및 탈주 (Rage-Quitting)**  
   - 1라운드에서 조기 탈락한 유저의 이탈, 무조건 의심(Call)만 누르는 트롤링 등으로 파티 플레이 외 공방 세션의 지속성이 취약함.  
4. **장기 메타 프로그래션(Meta-Progression) 부재**  
   - 세션 종료 후 남는 보상이 단순 화폐나 치장품에 그쳐, 플레이어가 연구할 수 있는 빌드 다양성 부족.

## 2. +α 혁신 프로젝트: 《Dead Man's Hand: Devil's Parlor》

> **"영혼을 저당 잡힌 도박사들이 악마의 살롱 지하 층을 돌파하는 덱빌딩 블러핑 로그라이크"**

### 2.1 핵심 차별화 요소 (+α Innovations)

| 번호 | 혁신 시스템 | 상세 설명 및 해결 과제 |
| :---- | :---- | :---- |
| **+α 1** | **싱글 로그라이크 층계 돌파 (Inscryption Style)** | 단순 단판 매칭이 아닌, 지하 1층(빈민가)부터 7층(악마의 VIP룸)까지 독특한 기믹을 가진 딜러 보스를 격파하는 솔로 로그라이크 캠페인 탑재. |
| **+α 2** | **전술적 속임수(사기 아이템) & 리스크 시스템** | 운에 의존하지 않고, 플레이어가 실시간 밑장빼기, 공포탄 바꿔치기, 소매 속 거울 확인 등의 '사기'를 칠 수 있음. 단, 상대의 집중도에 따라 적발 시 즉사/즉시 격발 페널티. |
| **+α 3** | **비동기 고스트 대전 (Asynchronous Ghost Matches)** | 실제 유저들의 플레이 기록(마우스 궤적, 망설인 시간, 블러핑 패턴)을 직렬화하여 '고스트 도박사'로 구현. 멀티플레이 대기 시간 및 탈주 문제를 100% 해소. |
| **+α 4** | **트위치/유튜브 실시간 시청자 개입 (Twitch EventSub)** | 시청자가 `!진실`, `!구라`를 투표하고, 최다 후원자의 닉네임이 리볼버 공이치기에 각인되어 방아쇠를 대리 격발하는 인터랙티브 스트리밍 기능 내장. |

## 3. 코어 게임플레이 루프 & 룰 상세

### 3.1 라운드 진행 플로우

1. **[덱 분배 및 탄창 로드]**:  
   - 덱에서 5장 드로우.  
   - 리볼버 6연발 실린더에 (실탄 N발 / 공포탄 M발 / 특수 저주탄 K발)이 무작위 장전되고 플레이어들에게 탄환 구성 공개.  
2. **[베팅 & 카드 제출]**:  
   - 선 플레이어가 테이블 기준 카드(예: "퀸 2장")를 뒷면으로 제출.  
   - 제출 전 1회 한정 [사기 행동] 가능 (예: 납 탄환 슬쩍 끼워넣기, 덱 밑장 훔쳐보기).  
3. **[의심(Call) or 통과(Pass)]**:  
   - 다음 플레이어는 15초 내에 의심할지, 추가 카드를 얹으며 통과할지 결정.  
4. **[서든데스 룰렛]**:  
   - 거짓 발각 시: 거짓말한 자가 자기 머리에 방아쇠 격발.  
   - 정직 증명 시: 의심한 자가 자기 머리에 방아쇠 격발.  
   - 공포탄이면 생존(턴 계속), 실탄이면 체력 1 차감(0이 되면 탈락).

### 3.2 전술적 사기 아이템 (Tactical Cheat Items)

- **소매치기 밑장빼기 (Bottom Deal)**: 자신의 패 1장을 덱 맨 아래 카드와 은밀히 교체. (기본 적발률 15%)  
- **납 탄환 바꿔치기 (Lead Weight)**: 실린더의 다음 탄환을 공포탄으로 교환. (기본 적발률 25%, 적발 시 상대가 내 머리에 조준)  
- **악마의 계약서 (Pact of Greed)**: 이번 턴 블러핑 성공 시 상대 체력 2 데미지. (실패 시 본인 즉사)  
- **탁자 밑 거울 (Under-table Mirror)**: 다음 챔버의 탄환 종류를 미리 확인. (기본 적발률 10%)

|               (Deck Shuffle, Chamber Randomization)                     |

+-------------------------------------------------------------------------+

                                    │

                                    ▼

+-------------------------------------------------------------------------+

|                           STATE_ROUND_START                             |

|                 (Deal 5 Cards, Trigger Passive Relics)                  |

+-------------------------------------------------------------------------+

                                    │

                                    ▼

+-------------------------------------------------------------------------+

|                           STATE_TURN_ACTION                             | <----------------------+

|  - Sub 1: Action_Use_Cheat ( 밑장빼기 / 챔버 조작 )                     |                        |

|  - Sub 2: Action_Play_Cards ( 카드 뒷면 제출 및 Value Claim )           |                        |

+-------------------------------------------------------------------------+                        |

                                    │                                                              |

                                    ▼                                                              |

+-------------------------------------------------------------------------+                        |

|                        STATE_CHALLENGE_WINDOW                           |                        |

|                (Timer 15s: Accept vs Call Bluff)                        |                        |

+-------------------------------------------------------------------------+                        |

             │                                              │                                      |

       [Call Bluff]                                      [Accept]                                  |

             │                                              │                                      |

             ▼                                              ▼                                      |

+--------------------------+                      (Next Player Turn) ------------------------------+

|   STATE_REVEAL_VERIFY    |

| (Check Claimed vs Real)  |

+--------------------------+

             │

             ▼

+-------------------------------------------------------------------------+

|                         STATE_ROULETTE_TRIGGER                          |

|             (Determine Loser -> Trigger Cylinder Spin)                  |

|                 Result: LIVE_AMMO or BLANK_AMMO                         |

+-------------------------------------------------------------------------+

             │

             ▼

+-------------------------------------------------------------------------+

|                          STATE_RESOLVE_DAMAGE                           |

|       - Blank: Health Unchanged, Tension Escalates                      |

+-------------------------------------------------------------------------+

             │                                              │

         (HP > 0)                                       (HP <= 0)

             │                                              │

             ▼                                              ▼

   [STATE_ROUND_START]                              [STATE_MATCH_OVER]

                                                    (Reward / Soul Lost)

## 5. 데이터 모델 및 시스템 아키텍처

### 5.1 엔진 선정: Unity (2022.3 LTS / 6) 또는 Godot 4.3+

- **권장 엔진**: **Godot 4.3 (C#)** 또는 **Unity**  
  - 가벼운 2.5D 하이브리드(로우폴리 3D 환경 조명 + 2D 스프라이트 캐릭터).  
  - 1인 개발에 최적화된 빠른 이터레이션과 빌드 경량화 (모바일/웹 포팅 용이).

### 5.2 데이터 스키마 (C# / JSON)

```csharp

// 1. 탄환 챔버 관리 클래스

public enum BulletType { Blank, Live, OccultCurse }

public class RevolverCylinder {

    private List<BulletType> chambers = new List<BulletType>();

    private int currentIndex = 0;

    public void SetupChamber(int liveCount, int blankCount) {

        chambers.Clear();

        for(int i=0; i<liveCount; i++) chambers.Add(BulletType.Live);

        for(int i=0; i<blankCount; i++) chambers.Add(BulletType.Blank);

        chambers.Shuffle(); // Fisher-Yates

        currentIndex = 0;

    }

    public BulletType PullTrigger() {

        if (chambers.Count == 0) return BulletType.Blank;

        BulletType fired = chambers[currentIndex];

        currentIndex = (currentIndex + 1) % chambers.Count;

        return fired;

    }

}

// 2. 비동기 고스트 데이터 구조체 (Ghost Profile)

[System.Serializable]

public class GhostTurnRecord {

    public int turnIndex;

    public float hesitationTimeSeconds; // 마우스 머무름/망설임 시간

    public List<int> submittedCardIds;

    public int claimedRank;

    public bool isBluffing;

    public bool attemptedCheat;

    public List<Vector2> cursorTrackSample; // 시선 트래킹

}

[System.Serializable]

public class GhostProfile {

    public string ghostId;

    public string playerName;

    public int floorLevel;

    public List<GhostTurnRecord> turns;

}
```

## 6. MVP 개발 로드맵 (8주 완성)

- **Week 1~2: 코어 피지컬 프로토타입**  
  - 리볼버 6연발 실린더 격발 엔진 및 손맛 사운드 FX.  
  - 테이블 카드 드로우, 카드 뒷면 내려놓기 및 1인칭 조작계 구축.  
- **Week 3~4: 상태 머신 및 싱글 AI / 사기 시스템**  
  - FSM 턴 루프 완성 (선언 -> 의심 -> 룰렛 격발).  
  - 사기 아이템 4종 및 들통 판정 알고리즘 탑재.  
- **Week 5~6: 비동기 고스트 레코더 & 플레이백 엔진**  
  - 로컬 플레이 기록 JSON 직렬화 및 고스트 AI 입력 주입기.  
  - 지하 3개 층 로그라이크 보스전 및 유물 15종 구현.  
- **Week 7~8: 트위치 연동 오버레이 & 스팀 데모 빌드**  
  - Twitch EventSub WebSocket 연동 투표 시스템.  
  - 사운드/포스트프로세싱(비네팅, 필름 그레인) 완성 후 스팀 넥스트 페스트 데모 추출.
